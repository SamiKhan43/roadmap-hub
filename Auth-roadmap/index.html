Learning path · IAM and Application Security · Beginner to Senior

Master identity and access, one step at a time.

From HTTP credentials and passwords to OAuth, OIDC, SAML, distributed identity and IAM architecture. 21 phases grouped into 6 levels, each with lessons, practice and a project. Finishing every topic does not make you senior: the milestones include architecture challenges.

Based on RFC 9700 (OAuth Security BCP, Jan 2025), NIST SP 800-63-4 (final 2025), OWASP Cheat Sheets and ASVS 5.0 (May 2025). OAuth 2.1 is an IETF draft, not a final standard. WebAuthn Level 2 is a W3C Recommendation; check W3C for later levels. Python outputs were run to produce them; HTTP, SQL, SAML and database examples are illustrative. Prefer maintained libraries and identity providers over custom protocol or crypto code in production.
