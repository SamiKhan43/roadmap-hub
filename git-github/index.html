A TEAM WORKFLOW

From issue to merged change

Git records the work. GitHub gives the team a place to discuss, review, and ship it.

  1. 01IssueDefine the problem and expected behavior.
  2. 02Feature branchIsolate work from the shared default branch.
  3. 03Changes & commitsImplement, test, and save focused snapshots.

RECOVER WITHOUT PANIC

Troubleshooting lab

Start by inspecting state and preserving work. Choose a problem for a diagnosis and safe recovery path.

Before recovery: check git status, save a copy of important work, and understand whether the history is shared. Rewriting published history can disrupt your team.
