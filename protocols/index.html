Software systems communicate through agreed rules: how messages are framed, addressed, delivered, secured, acknowledged and recovered when things go wrong. This library explains those rules and the machinery behind them.

Follow a web request through the stack. DNS usually resolves the name first; then the connection takes one of two common paths:
HTTP/1.1 or HTTP/2 → TCP → TLS → IP → link
HTTP/3 → QUIC (with TLS 1.3) → UDP → IP → link

These are simplified paths; DNS, proxies, caches and network configuration can change the exact exchange.
