# Memory Management — Module 02

Part of the Roadmap Hub Architecture Library.

## Overview

This module explains how computers and operating systems manage memory.

It covers:

1. What Is Memory Management?
2. How a Program Uses Memory
3. Memory Addresses and Address Spaces
4. Stack Memory
5. Heap Memory
6. Stack vs Heap
7. Memory Allocation and Deallocation
8. Virtual Memory
9. Physical Memory vs Virtual Memory
10. Paging and Page Tables
11. Memory Protection and Isolation
12. Memory Leaks and Fragmentation
13. Garbage Collection
14. How the OS Manages Memory
15. Memory Management in Backend Applications

## Files

- `index.html` — Module structure
- `memory-management.css` — Module styling
- `memory-management.js` — Navigation, rendering and progress
- `lessons-data.js` — Lesson content and quizzes

## Technology

- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage

No framework, backend, package installation or build step is required.
