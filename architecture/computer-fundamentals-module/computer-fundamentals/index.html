Your lessons

    What you will understand

    From physical components to running software

    Every backend application runs on a computer. Its code needs a processor to execute instructions, memory to hold active work, storage to preserve data, and an operating system to coordinate access to those resources.

    This module builds that picture one layer at a time. You will start with the computer as a complete system, then examine the CPU, memory, binary data, program execution, and the operating system's protection boundary.

    How to use this module

    Learn in sequence, then check your understanding

    • Start with lesson 01 and move forward using Previous and Next navigation.
    • Each lesson uses an everyday analogy, walks through what happens inside the system, includes a diagram, and connects the idea to backend work.
    • Answer the knowledge check questions to receive immediate explanations.
    • Mark a lesson complete when you are comfortable with the key ideas. Your progress is saved in this browser.
    Learning goal: Be able to explain what happens between a program starting and its instructions running on hardware, and describe the services the operating system provides.

    Where this leads

    Preparing for the next modules
